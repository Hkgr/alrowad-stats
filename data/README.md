# data

مجلد البيانات المحلية. **لا يُرفع منه إلى Git إلا هذا الملف**؛ ملفات المصدر (xlsx وغيرها) تبقى على جهازك فقط.

- `raw/2025/` و`raw/2026/`: ملفات المصدر الأصلية للمؤسسة.
- `processed/`: مخرجات المعالجة (مستقبلًا).
- `Projects List_*.xlsx`: قائمة المشاريع والمسارات (مرجع لتحديد مسار كل مشروع).
