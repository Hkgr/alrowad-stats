# frontend

واجهة «إحصاءات الرواد»: React 19 + TypeScript + Vite + Tailwind CSS 4 + TanStack Query + ECharts.
أوامر التشغيل في [../README.md](../README.md).

```
src/
  App.tsx                    المزودات والمسارات
  assets/brand/              الشعار الأصلي (هوامش مقصوصة فقط)
  layout/SiteHeader.tsx      الرأس: الشعار، الفترة، بحث المشاريع، وضع العرض
  components/ui/             بطاقات وأزرار وتبويبات وحالات (تحميل/غياب بيانات/خطأ)
  components/charts/         غلاف ECharts وثيم الرسوم ولوحة الألوان المتحقق منها
  features/dashboard/        الصفحة بمستوياتها الثلاثة، حالة الاستكشاف (URL)، الاستعلامات، المكونات
  services/api/              عميل API
  types/api.ts               أنواع العقود (انظر ../api/README.md)
  lib/, hooks/               الأرقام والعدّ العربي والبحث، الدخول المتدرج، ملء الشاشة، تقليل الحركة
```

لا توجد أسماء مسارات أو مشاريع أو مكاتب أو أرقام ثابتة في الكود؛ كل شيء من `/api/v1`.
(الأيقونة واللون لكل مسار عرض فقط: الأيقونة برمز المسار، واللون بترتيبه.)
